# alist部署教程：脚本和 Docker 两种装法，含服务器配置选择与装完必做的安全设置

AList 是一个开源的文件列表程序，用 Go 和 SolidJS 写成，遵循 AGPL-3.0 协议。它把阿里云盘、OneDrive、Google Drive、百度网盘、S3、FTP、本地目录这些存储挂进同一个网页界面，自带视频播放、Office/PDF/Markdown 预览和 WebDAV 接口。软件本身不收费，你要花的钱只有服务器。

部署本身不复杂：官方脚本三行命令，或者一份 Docker Compose 文件，Debian 12 和 Ubuntu 20 上都验证过。真正容易翻车的是装完之后——端口没改、站点标题没换、guest 没关，你的私人文件可能正被搜索引擎收录。

## 先选服务器：跑 AList 需要什么配置

AList 对 CPU 和内存的要求不高，真正影响体验的是带宽、月流量包和硬盘容量。选服务器别被「4核8G」这类数字带着走。

按用法分：

- 只挂网盘、自己偶尔看视频：2核2G 足够
- 几个人共用、经常播放高码率视频：带宽 6M 起步更稳
- 要跑离线下载、把服务器硬盘当存储用：硬盘和流量包都要加

这里有个容易忽略的区别。AList 播放网盘里的文件时走的是 302 重定向，你的服务器只发一个跳转指令，数据由客户端直接从网盘拉取，服务器带宽压力很小。但播放服务器本地硬盘里的文件、或者通过 WebDAV 读写，流量就实打实走服务器，轻量服务器的月流量包用超了会限速。同样是「看视频」，两种用法对配置的要求差很远。

## 部署前要准备什么

四样东西：一台 Debian 12 或 Ubuntu 20 的服务器、公网 IP、一个 SSH 工具、放行好的端口。

SSH 工具推荐 Finalshell，有图形化文件管理界面，后面改配置文件不用敲命令，直接双击打开改完保存就行。用系统自带终端也完全没问题。

端口要在腾讯云控制台的防火墙里提前放行。端口没放行的话，装得再对也访问不了。下单时地域选离自己近的，镜像直接选 Debian 12 或 Ubuntu 20，省得装完再重装系统。

## 方法一：官方脚本安装，三行命令

想最快看到界面，选这个。

bash
curl -fsSL "https://alist.nn.ci/v3.sh" | bash -s install


以后要升级或卸载：

bash
curl -fsSL "https://alist.nn.ci/v3.sh" | bash -s update
curl -fsSL "https://alist.nn.ci/v3.sh" | bash -s uninstall


装完先设密码：

bash
cd /opt/alist
./alist admin set 你的新密码


默认用户名是 admin，登录后台后可以改。

默认端口 5244 建议改掉。打开 `/opt/alist/data/config.json`，把 `"http_port": 5244` 改成别的五位数，保存后重启：

bash
systemctl restart alist


浏览器访问 `http://服务器IP:端口`，能看到登录页就说明装好了。

## 方法二：Docker Compose，适合长期维护

想把数据集中管理、以后可能在同一台机器上加别的服务，用这个。

新建 `compose.yaml`：

yaml
version: "3.3"
services:
  alist:
    container_name: ${STACK_NAME}_app
    image: "xhofe/alist:${APP_VERSION}"
    volumes:
      - ${STACK_DIR}:/opt/alist/data
    ports:
      - ${APP_PORT}:5244
    environment:
      - PUID=0
      - PGID=0
      - UMASK=022
    restart: always


同目录下建 `.env`：


STACK_NAME=alist
STACK_DIR=./alist
APP_VERSION=latest
APP_PORT=5244


执行 `docker compose up -d` 启动。

compose 里的 PUID=0、PGID=0 是为了让容器有权限读取宿主机目录，照着写就行，改成普通用户 ID 反而可能挂载失败。改端口就改 `.env` 里的 APP_PORT，重新 `docker compose up -d` 生效。

Docker 方式下设管理员密码同样是 `alist admin set` 子命令，只是需要通过 `docker exec` 进容器执行。

**脚本还是 Docker？** 脚本装完文件在 `/opt/alist`，适合只想快点用起来；Docker 的数据都在一个目录里，备份就是打包带走，迁移到新服务器也简单。

十分钟，做完这五件：

1. 改掉默认用户名 admin
2. 设置一个不简单的密码
3. 确认 guest 用户处于禁用状态（默认禁用；要分享文件再开，并单独限制可见路径）
4. 改站点标题，默认的「Alist」辨识度太高，换个随机的名字
5. 改端口，别用 5244，也别用 80、443、5678

这五条做完，被顺手扫到的概率会低很多。

## 常见问题

**AList 收费吗？**
不收费。AGPL-3.0 开源协议，软件本身免费，花钱的只有服务器。

**最低什么配置能跑？**
AList 是个轻量程序，低配也能跑起来。稳妥选 2核2G，配置主要影响的是挂载数量和多人并发播放。

**脚本和 Docker 怎么选？**
想十分钟看到界面选脚本；想方便备份迁移、以后在同一台机器跑别的容器选 Docker。

**装完访问不了怎么排查？**
两个检查点：腾讯云控制台防火墙有没有放行端口；服务在不在运行（`systemctl status alist`）。

**流量会被跑光吗？**
看用法。挂网盘在线播放走 302 重定向，客户端直连网盘，服务器流量消耗小；播放服务器本地文件或 WebDAV 读写走服务器流量，超过月流量包会限速。
